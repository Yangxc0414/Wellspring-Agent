Regression-test inscription hypothesis for bug-fix commits

lens: mechanism · refs: LOCAL-98e4a05ec9-S01-01, LOCAL-e1250746bb-S01-02, LOCAL-f801f48b67-S01-01

hypothesis: In Python projects, commits labelled as bug fixes are more likely than feature commits to modify test files because fixes tend to add or update regression tests that reproduce the defect; the association should hold when comparing commits within the same project rather than only across pooled projects.

falsification: The hypothesis is falsified if, after within-project matching on commit size and time, bug-fix-labelled commits show the same or lower test-touch probability than feature commits, or if the direction reverses under an alternative SZZ label.

Testing-infrastructure boundary on the bug-fix test-touch gap

lens: boundary · refs: LOCAL-cd936ad44a-S01-01, LOCAL-98e4a05ec9-S01-01

hypothesis: The bug-fix versus feature test-touch difference in Python projects is strongest in repositories with visible test automation and should attenuate in repositories whose test suites are absent, ad hoc, or not run by CI; project stratification by test-infrastructure maturity should therefore reveal a boundary condition.

falsification: The boundary hypothesis is falsified if the bug-fix test-touch gap is equally strong in low-test-infrastructure and high-test-infrastructure strata, or if the sign of the gap is inconsistent across those strata.

SZZ label-definition sensitivity

lens: measurement · refs: LOCAL-98e4a05ec9-S01-01, LOCAL-e1250746bb-S01-02, LOCAL-f801f48b67-S01-01

hypothesis: The observed tendency for bug-fix commits to touch tests in Python projects is sensitive to how bug-fix commits are identified: SZZ variants that differ in linking fixes to prior changes should produce different test-touch contrasts, so a robust effect must persist across label definitions rather than only under one local labelling heuristic.

falsification: The hypothesis is falsified if all tested SZZ or labelling variants yield a stable, same-direction test-touch contrast with no meaningful sensitivity, or if the contrast disappears only because one label definition systematically misclassifies feature commits.

Project-stratified survival of the test-touch contrast

lens: boundary · refs: LOCAL-98e4a05ec9-S01-01, LOCAL-cd936ad44a-S01-01

hypothesis: In Python projects, the positive bug-fix test-touch contrast survives stratification by repository, project age, and commit size, but the within-stratum magnitude is expected to be larger in mature repositories with established test suites than in young repositories where feature development also introduces tests.

falsification: The hypothesis is falsified if within-project stratified comparisons show no consistent positive contrast, or if the contrast is fully explained by stratification variables such as commit size, repository age, or project identity.

Flaky-test remediation confound

lens: mechanism · refs: LOCAL-2f5a3feff8-S01-01, LOCAL-cd936ad44a-S01-01, LOCAL-98e4a05ec9-S01-01

hypothesis: A portion of the apparent excess test-touching by Python bug-fix commits is attributable to flaky-test remediation or test-stability changes that are misclassified as bug fixes; after excluding commits whose test changes target flaky or nondeterministic tests, a residual bug-fix test-touch contrast should remain if the underlying association is real.

falsification: The hypothesis is falsified if excluding flaky-test-related test changes leaves the bug-fix versus feature contrast unchanged, or if the contrast vanishes entirely and no residual association remains.

Path-level versus test-semantic operationalization

lens: measurement · refs: LOCAL-98e4a05ec9-S01-01, LOCAL-cd936ad44a-S01-01, LOCAL-f801f48b67-S01-01

hypothesis: In Python projects, the bug-fix test-touch difference is partly an artifact of treating any modified path under a test directory as a test touch; a stricter operationalization requiring changed test cases, assertions, or fixtures should preserve a same-direction contrast if bug-fix commits genuinely engage test semantics more than feature commits.

falsification: The hypothesis is falsified if the path-based test-touch contrast is positive but the stricter test-semantic contrast is zero or negative, or if both operationalizations agree only because test-directory paths perfectly proxy semantic test changes.
