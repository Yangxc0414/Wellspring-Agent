# 95-配方候选 R1/R2：硬化记忆与形状修复回路（14/14）

> 状态基线：2026-11-18。承接 93（首轮 12/14）、94（配对 12/14 vs 12/14）。
> 本轮把两个候选配方做成可执行选项，并在同一张冻结任务卡上复测。
> 边界：每臂 n=1，模型有采样随机性；R1 的约束来自 baseline 的失败观察，因此任务 A 对 R1/R2 已不再是严格 held-out（见 §4）。

## 1. 候选配方

### R1：硬化记忆包（hardened pack）

在 failures 节末尾追加 4 条硬约束（数据变体，不改代码）：

```text
- primary_metric MUST be a short identifier (e.g. success_rate, accuracy, mutation_score); never a sentence
- budget MUST state numbers (seeds x evaluations, token cap, or wall-clock cap); never 'not specified' or prose only
- controls MUST list >=2 concrete comparison conditions
- every number in any section must trace to an evidence span id or a signed claim
```

生成方式：`memory-pack-idea.json` + 约束 → `memory-pack-idea-hardened.json`。

### R2：形状修复回路（repair loop）

新增 `--experiment-repair`：S4 草稿返回后检查两个形状（metric 是否标识、budget 是否含数字）；不达标则带上 `repair_errors` 与 `previous_draft` **重写一次**。仍是草稿，不替代 G2。

- 代码：`research_agent/cli.py` 的 `_wrap_with_experiment_repair`；
- 测试：`tests/test_experiment_repair.py` 3 例（坏形状触发一次重写、好形状不重写、非 dict 原样返回）；
- provenance：结果与 `demo.json` 记录 `experiment_repair: true`。

## 3. 诚实读法

1. **n=1/臂，模型有采样随机性**：不能据此声称 R1 优于 R2，也不能声称提升幅度；
2. **R1 的约束是"教到点上"**：约束直接来自 FA-20261118-03（metric 句子 / budget 不可测），所以它在这张卡上有效几乎是构造性的；
3. **R2 更像机制改进**：修复回路不针对某句话，而是"检查→带错误重写"，理论上可迁移；
4. **任务 A 对 R1/R2 已不是严格 held-out**：我们在 A 上看到失败后才写约束；**B/C 两张冻结卡尚未执行**，它们才是下一轮的无偏测量；
5. **评分仍是符合性**，不代表研究质量；paper 轴全过也只说明引用/结构/边界合规。
