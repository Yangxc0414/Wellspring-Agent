# 标签化梳理：共性与差异的提取变成可复现数据

> 状态基线：2026-11-21。承接 153（三维建模 0.2）、154（要素端口与组合）、研讨纪要待办事项 #2（@周鑫汐 @杨想成：标签化梳理各方法步骤，提炼共性与差异）。
> 本文把方法注册表从 0.2 升到 **0.3**（新增共享标签词表 `tag_vocabulary` + 每方法 `tags`），校验 fail-closed；前端方法模型页新增 **标签 × 方法** 共性/差异提取视图。注册表的既有字段与门禁语义未动。

## 0. 一句话结论

导师在纪要里给的第一步是"先对各类研究方法的具体步骤进行**标签化梳理**，以提炼其共性与差异，再基于此进行抽象建模"——并批评"凭感觉做事"。本轮把这一步做成**可复现的数据计算**：32 个标签的共享词表（每个带定义与文献依据）+ 九方法的标签标注（每个标签可溯源到该方法已注册的协议字段/检查项/任务卡）+ 分组提取（共性 ≥3 方法 / 部分共性 2 / 本质差异 1）。

## 1. 提取结果（数据说话）

- **共性（≥3 方法）**：`伦理审查`（案例/调查/行动研究）、`预注册协议`（受控实验/仓库挖掘/SLR）——治理类标签跨方法成立；
- **部分共性（2 方法）**：`抽样框`（挖掘+调查）、`对照组`（受控+准实验）；
- **本质差异（单方法独有）**：`随机化`（受控实验独有——正是纪要"实验必须同时满足受控与随机"）、`三角验证`与`链式证据`（案例研究独有）、`介入循环`（行动研究独有）、`污染控制`/`饱和分析`（基准评测独有）、`识别策略`（准实验独有）等 28 项。

**这就是"受控随机的实验与案例研究的区别"的可复现形式**：实验的本质标记是随机化+功效分析+停止规则；案例研究的本质标记是三角验证+链式证据+编码本。两个方法在同一治理骨架上的差异，由标签层直接读出，不再依赖任何人的口头归纳。

## 2. 设计要点

1. **共享词表**（32 项）：每条带定义 + 文献/检查依据；方法标签必须落在词表内（fail-closed 校验：方法引用词表外的标签 → 拒绝加载）；
2. **溯源纪律**：每个方法的标签都能指回它已注册的协议字段/检查项/任务卡（如 mining 的"快照哈希"指向 stage_tasks S5 与 run contract evidence.hash）——标签是已有数据的**索引**，不是新的发明；
3. **schema 0.2 → 0.3**：validate 对 tag_vocabulary（definition/basis 必填、无重复）与 method.tags（非空、全部在词表内）fail-closed；tests 同步（含"标签在词表外被拒绝"的负例）；快照重导；
4. **前端**：方法模型页新增 **标签 × 方法** 提取视图（按 共性/部分共性/本质差异 分组，每条带定义、方法 chips、依据）；方法详情卡加标签 chips。

## 4. 设计主张（可证伪）

1. "标签化梳理"的正确形态是**共享词表 + 溯源标注**，而不是自由文本标签——词表使共性提取可计算，溯源使标签不漂移；
2. 提取结果验证了纪要的两个点名判断：随机化是受控实验的本质差异标记、三角验证是案例研究的本质差异标记——它们都落在"单方法独有"组；
3. 预注册协议与伦理审查跨 ≥3 方法成立，说明**治理类标签具有跨方法共性**——与"治理槽位不变"（149）互为印证。

## 5. 边界与下一步

- 标签是**人工策展**的（每方法 2–7 个），不是从文本自动抽取——可复现指"提取共性的计算"，标签本身的更新须随 registry 演进走同一迁移流程；
- task-compare 表可加"标签差异"行（下轮）；
- 标签层为方法组合（154）提供了第二维度：组合提案可按"新增标签的方法组合"作区分——实现仍需后端 SPEC 先行。
