## 2. /app/ 来源标签统一

之前工作台内部有 `LIVE RUNTIME / SNAPSHOT / 演示数据 · 静态 / API · LOCAL` 等多套口径；ESE 运行面板用的是 `LOCAL RUNTIME / STATIC SNAPSHOT / NO DATA`。本轮统一：

| 位置 | 旧 | 新 |
| --- | --- | --- |
| SourcePill（设置/概览） | LIVE RUNTIME / SNAPSHOT / STATIC | LOCAL RUNTIME / STATIC SNAPSHOT / NO DATA |
| TopBar 状态徽章 | 静态演示 · RUNTIME 已禁用 / API · LOCAL / 演示数据 · 静态 | STATIC SNAPSHOT · runtime 禁用 / LOCAL RUNTIME · 已连接 / STATIC SNAPSHOT · 无 runtime |
| ContextPanel 页脚 | RUNTIME · X / 演示数据 · 无 worker | LOCAL RUNTIME · X / STATIC SNAPSHOT · 无 runtime |
| StaticModeNotice | 静态演示模式 | STATIC SNAPSHOT · 静态演示构建 |

含义保持一致：**LOCAL RUNTIME = 连上本地 runtime；STATIC SNAPSHOT = 构建快照/无 runtime；NO DATA = 连快照都没有**。测试 `tests/test_web_labels.py` 钉住这三处文案。
