# 对比表补"标签差异"行：本质差异的计算化呈现

> 状态基线：2026-11-21。承接 155（标签化梳理）、150（实证任务对比表）与用户"继续"指令（159/161 队列第一项）。

## 0. 一句话结论

实证任务对比表补齐最后一块：**标签差异（单方法独有）**行——每列显示该方法独有、其余对比方法没有的标签（ESE 列：抽样框/时间切分/去重策略/标签启发式声明/许可核对/快照哈希——"预注册协议"因与受控实验共享被正确排除）。至此"受控随机的实验与案例研究的本质差异"从纪要要求变成了**表上一行可读的计算结果**。

## 1. 派生语义

`uniqueTags` = 该方法标签集合 − 对比集合中其他方法的标签并集（单方法持有才计入）。**共享标签不进差异行**（如"预注册协议"为受控实验与仓库挖掘共享）——共享正是共性的证据，只报差异才是诚实的对比。测试钉住：两方法共享"消融实验"、独有"随机化"/"三角验证"时，uniqueTags 精确等于各自独有集。

## 3. 设计主张（可证伪）

1. 对比表的完备维度至此收口：方法 profile / 证据源 / 主指标 / seeds / **基线策略** / 断言（主张+范围） / **标签差异** / 已走槽位 / 开着的门——九行覆盖"这任务是什么研究、凭什么、差在哪"的全部可读面；再增行需要新的证据维度论证；
2. 差异行的语义是"单方法独有"而非"不同"：共享标签被排除，避免把共性误读成差异。
