## 0. 结论先行

仓库"看起来乱"的主要来源不是模块多，而是三类可机械发现的东西：

1. **本地缓存混进仓库树**：`research_agent/vendor/astradraw/.local/runs/mvcc-method/` 下 17 个 Edge 浏览器 profile（**117 MB**、约 5000 个文件）——纯缓存，随 vendor 一起被排除出发布，但让克隆、搜索、磁盘全部变慢。
2. **同一份内容写两遍**：`README.md` 的"当前事实基线"一节 62 条里 **59 条**逐字出现在 `docs/fact-baseline.md`（26 KB 重复），两份已经漂移（fact-baseline 48 KB vs README 26 KB）。
3. **生成副本与源不一致，且构建脚本静默跳过**：`scripts/build-site.mjs` 的 `copyDocs` 仍指向**已被移走**的根目录 `16-/17-/18-/71-` 文档，`fs.existsSync` 失败只打 warning → 提交在 `site/docs/` 的副本从此不再更新（漂移不可见）。

这三类问题都不靠"删文件"解决，而靠**一个可运行的检查器**防止复发。

## 2. 代码级改动（不是只写文档）

### 2.1 `scripts/repo_hygiene.py`

只读、无第三方依赖，四类检查：

| 检查 | 判定 | 为什么需要 |
| --- | --- | --- |
| `site_copy_drift` | 生成副本与源 sha256 不一致 → **blocker** | 本次漂移的根因就是没人比对 |
| `site_source_missing` / `site_copy_missing` | 声明了但不存在 → blocker | 防止 `skip missing doc` 再次静默 |
| `workflow_path_missing` | `paths:` 里的字面路径不存在 → blocker（glob 跳过） | 6 条失效路径躺了很久 |
| `local_cache_in_tree` | vendor 下出现 `edge-profile*` → blocker | 117 MB 缓存复发即红 |
| `large_dir` / `duplicate_source` | 仅 warning | 参考仓库与运行数据本来就大；重复只提示 |

接入方式：CI pinned 列表 + `AGENTS.md` §6 完成定义。**它自己不修改任何文件**。

### 2.2 `storage.py` 成为唯一的哈希/时间原语

改动前：

```text
research_agent/closure.py        _now / _sha256_bytes / _sha256_file
research_agent/modules/run.py    _now / _sha256_bytes / _sha256_file      （逐字相同）
research_agent/lineage.py, feedback.py, verdict_ledger.py ... 另有各自的 _now/_rel
```

改动后：`storage.sha256_bytes / sha256_file / now_iso` 是唯一实现；closure 与 run 删除本地副本并改为导入。行为不变（同样的 bytes、同样的 ISO 秒精度），因此只升 patch：

- `modules/closure/SPEC.md` 0.18.1 → **0.18.2**
- `modules/run/SPEC.md` 0.7.2 → **0.7.3**
- 跑 `python -m research_agent workspace export`，`tests.test_workspace` 通过。

> 为什么先做这两个：它们是被复制的**相同语义**，且都有完整测试；这类改动最容易验证"行为不变"。其余 `_now` 副本（custom_agents / evolution_policy / literature_memory / skill_registry / workspace）留到各自模块下一次实质修改时顺手收敛，避免一次跨 7 个模块的大 diff。

### 2.3 站点构建不再静默降级

`copyDocs` 原来的分支：

```js
if (!fs.existsSync(sourcePath)) { console.warn("skip missing doc:", source); continue; }
```

改为抛错。理由：生成副本与源不一致是**交付面错误**，不是可忽略的本地环境差异；warning 在 CI 日志里没人看。

## 6. 一句话总结

**清洁不是"删得多"，而是"漂移会被自动发现"。** 本轮删掉了 117 MB 缓存和 25 KB 重复文档，但真正的产出是 `repo_hygiene.py`：它让"生成副本与源不一致""工作流路径失效""缓存混进仓库"这三类问题从**靠人记得**变成**CI 变红**。
