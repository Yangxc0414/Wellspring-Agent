| 级别 | 定义 | 当前 |

## 3. 未验证面（按严重度）

1. **官方路径未验证**：localqa 是本地扩展（SearchQA 子类、env=None），上游 31 个 benchmark 全部要求 Docker——容器内的隔离语义、`_model_egress` 中继、官方数据集切分都未跑过。分数不可与榜单比较。
2. **供给≠外部模型**：宿主作答（同供给），token/费用全 0（shim 不报用量）；这是接口证据，不是研究结果。
3. **题池饱和**：12 道演示题、基线满分，**没有观察到"演化提升分数"**——观察到的只是门禁语义（平局拒收）。test 仅 3 题，统计意义为零。
4. **覆盖面极窄**：1 算法（skillopt）× 1 harness（miniagent）× k=1 × 1 epoch。skillopt 的 merge/rank/slow-update 分支**均未触发**（单条 patch、无合并、无慢更新）；上游"13 算法 × 31 基准 × 7 harness 统一接口"的主张未被检验。
5. **未进我们的治理闭环**：直跑 CLI，无 ExecPort dispatch 记账、无 claim/EA/capsule、无 closure/lineage——从本平台视角它仍是"文件夹里的证据"，不是"链上的证据"。
6. **上游版本未 pin**：FlashRSI-main 是 zip 快照（无 `.git`），无 commit hash；只能以本地文件哈希标识。FlashRSI 自身测试套件本次未跑（74 记录过 Windows 部分失败）。
7. **复跑依赖宿主在线**：宿主供给需要持续应答；`NO_PROXY` 补丁是机器特定环境修复。

## 4. 最小升级路径（按成本排序）

1. **L1.5（小）**：localqa 难题池（基线 <1.0）+ 预注册判据 → 观察"被采纳的改进"（76 §5②）。
2. **L3（小-中）**：exec-port 注册 flashrsi 面 + memory-ab/experiment claim seam（80 方向修正后的最小 SPEC 修改）→ 外部引擎产出进同一判定总线。
3. **L2（决策项）**：装 Docker（WSL2/重启成本）+ 外部 API key → 上游原生 benchmark 至少跑一个（如 searchqa supplied_context），同时获得真实 token/成本读数。
4. **版本纪律**：对 FlashRSI-main 记录文件清单 + 目录 SHA-256，写入运行元数据；或将 zip 快照换成 `git clone` 固定 commit。
